# 🌾 Planting Game - 农场物语

一个使用 Python 和 Pygame 开发的农场种植游戏，灵感来自《星露谷物语》。

## 📖 项目简介

这是一个2D农场模拟游戏，玩家可以控制角色在农场中移动，开垦土地、种植作物、浇水加速生长、等待作物成熟并收获产品出售赚取金币。

## ✨ 游戏特色

- 🌱 **多种作物**：小麦、番茄、玉米、南瓜、胡萝卜等多种作物可种植
- 🌿 **季节系统**：春夏秋冬四季轮换，不同作物适合不同季节
- 💧 **浇水系统**：浇水可加速作物生长
- 💰 **金币系统**：出售作物产品赚取金币
- 🏪 **商店系统**：购买各种种子
- 📦 **背包系统**：物品堆叠，方便管理
- 🎮 **角色动画**：角色根据移动方向改变朝向

## 🛠️ 技术栈

- **Python 3** - 主要开发语言
- **Pygame** - 游戏开发框架，用于图形渲染和事件处理

## 📁 项目结构

```
planting-game/
├── main.py           # 游戏主入口，包含游戏循环和主要逻辑
├── block.py          # 土地块类定义（Block、Soil）
├── character.py      # 角色类定义，包含背包和金币管理
├── item.py           # 物品类定义（Item、ItemType、Plant、Season）

```

### 核心模块说明

#### `main.py` - 游戏主程序
- 初始化 Pygame 和游戏窗口（800x600）
- 创建玩家角色和初始物品（锄头、水壶、种子）
- 生成土地块网格
- 处理游戏主循环：事件监听、渲染更新、植物生长逻辑
- HUD 显示（金币、季节、天数）
- 商店和背包界面

#### `block.py` - 土地系统
- **Block 类**：基础土地块，包含位置和状态属性
- **Soil 类**（继承Block）：可种植的土地
  - 支持开垦（cultivate）
  - 支持种植（plant_crop）
  - 支持浇水（water）- 加速生长
  - 支持生长（grow）- 基于时间的生长系统
  - 支持收获（harvest）

#### `character.py` - 角色系统
- 角色位置和朝向管理
- 金币系统：添加、消费金币
- 背包系统：物品堆叠、添加、移除、查询物品
- 种子选择系统

#### `item.py` - 物品系统
- **ItemType 类**：物品类型枚举（工具、种子、植物、产品）
- **Season 类**：季节枚举（春、夏、秋、冬）
- **Item 类**：基础物品定义，支持价格和堆叠
- **Plant 类**（继承Item）：植物定义，包含生长时间、产出物品、种子掉落、适合季节等属性
- **create_crops()**：创建所有预定义作物

## 🎮 游戏操作

| 按键 | 功能 |
|------|------|
| W | 向上移动 |
| A | 向左移动 |
| S | 向下移动 |
| D | 向右移动 |
| 空格 | 交互（开垦土地/种植/收获）|
| R | 浇水（加速作物生长）|
| TAB | 切换当前选择的种子 |
| E | 打开/关闭背包 |
| B | 打开/关闭商店 |
| Q | 在背包中出售所有产品 |

## 🌱 游戏玩法

1. **开垦土地**：站在未开垦的土地上，按空格键使用锄头开垦
2. **选择种子**：按 TAB 键切换想要种植的种子类型
3. **种植作物**：站在已开垦的土地上，按空格键种植（注意季节限制！）
4. **浇水加速**：按 R 键给作物浇水，可以加速生长
5. **等待生长**：作物会随时间自动生长，生长阶段以数字显示
6. **收获产品**：作物成熟后（显示感叹号），按空格键收获产品和种子
7. **出售赚钱**：按 E 打开背包，按 Q 出售所有产品换取金币
8. **购买种子**：按 B 打开商店，点击 Buy 按钮购买新种子

## 🚀 如何运行

```bash
# 安装依赖
pip install pygame

# 运行游戏
python main.py
```
